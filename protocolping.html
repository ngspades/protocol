Ping

This page documents the raw UDP protocol of a server: the classic ping and LAN discovery, and our HELLOINFO (server details) and map preview. No ENet and no packet id: the first bytes of the datagram are the packet.

Connection

Open a raw UDP socket and send the datagram to the server's game port (32887 by convention). A server answers with a datagram to the source address.

UDP proves nobody's address, so a query is also a way to make a server send its answer to a forged victim. Our server therefore budgets answers per source address, and every answer is no larger than its query where it matters. Pad HELLOINFO to 1200 bytes: the padded query gets 5 answers a second (burst 10) per address, the bare 9-byte word only 0.5 (burst 3).

Ping LAN

Client -> Server

LengthValueField TypeNotes
8 bytesHELLOLANStringfixed length

A server answers only to a local address (10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, ::1, fc00::/7, fe80::/10). Send it as a broadcast and to 127.0.0.1 on ports 32882..32897 to find servers on the local network.

Map Preview

Client -> Server

The details panel can show the map's top view. It is a 256 x 256 RGB picture, zlib-compressed, framed as:

"SDP1" | Uint16 width | Uint16 height | zlib(RGB rows)

row 0 is map y 0. info.map_preview is the length of that stream and info.map_shape identifies it.

Ask for it in pieces:

LengthValueField TypeNotes
1200 bytesHELLOPREVIEW + Uint32 offset + paddingString + Uint32the query must be padded; a short one is refused

Map Preview Answer

Server -> Client

Field NameField TypeNotes
Magic4 bytes"SDPC"
TotalUint32the whole stream's length

Shape64 bytesthe map's shape, hex, no NUL
DataUint8 arrayup to query size - 72 bytes of the stream

The answer is never larger than the query, so a forged source amplifies nothing. Keep up to 8 chunks in flight, ask again every 0.5 s, and give up after 3 s without a chunk (a slow link is not a failure). Check SDP1, the size and the inflate before showing it, and cache by map_shape. A browser cannot send UDP, so a web client has no preview.
