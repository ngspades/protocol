ngspades Protocol Documentation

This page documents the networking protocols of Ace of Spades 0.75/0.76 and ngspades 1.0, for anyone writing a client or a server that should play with them.

Overview

Ace of Spades uses the ENet networking library for all server-client communication. The 0.75 information comes from the original pyspades source and the clients that speak it, plus the extensions ZeroSpades registered for it, collected in the aosprotocol specification and spoken by ngspades-client. 1.0 starts from the abandoned ngspades branch of OpenSpades (yvt's "strengtheningAo" work); the ngspades organization is reviving it, and ngspades-server speaks protocol 1.0, its finished and documented form.

Versions

  • 0.75 and 0.76 — the classic protocol public servers speak.
  • 1.0 — the protocol of ngspades-server.
  • Extensions — the 0.75 extension registry.
  • Master Server and Ping — the lists, WebRTC signalling, tokens and the raw UDP queries.
  • Examples — C and Godot code for the codecs and the connections.
